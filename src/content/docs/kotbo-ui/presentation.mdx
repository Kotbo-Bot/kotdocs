<p class="doc-lead"><strong>Kotbo-UI</strong> (<code>@kotbo/ui</code>) centralise les composants d'interface Svelte 5, le système d'icônes <code>Papicon</code> et les graphiques <strong>Analytics v3</strong> utilisés dans le dashboard Kotbo et dans AegisAI.</p>

## Pourquoi un paquet dédié

* **Zéro duplication** : les primitives UI, modales, sélecteurs et courbes Analytics v3 sont maintenus à un seul endroit.
* **CSS 100 % autonome** : aucune dépendance à Tailwind CSS dans `@kotbo/ui`, ce qui lui permet de fonctionner aussi bien dans **Kotbo Dashboard** (Tailwind v4) que dans **AegisAI** (CSS natif avec jetons modernes).
* **i18n découplée** : textes français par défaut, personnalisables à chaud sans lier le paquet à Paraglide-JS.
* **Sous-exports JS purs** : les fonctions de calcul et actions DOM sont importables directement sous `bun test` sans compilateur Svelte.

## Installation avec Bun

Installez le paquet npm `@kotbo/ui` avec **Bun** :

```bash
bun add @kotbo/ui
```

Ou déclarez-le dans le `package.json` du projet hôte puis exécutez `bun install` :

```json
{
  "dependencies": {
    "@kotbo/ui": "^0.1.0"
  }
}
```

Dans le point d'entrée de l'application (`main.ts`), chargez `@kotbo/ui/styles` avant votre feuille CSS applicative :

```ts
import '@kotbo/ui/styles';
import './app.css';
```

## Comment Kotbo et AegisAI le consomment

* **Kotbo Dashboard** conserve tous ses points d'entrée locaux dans `src/lib/components/**` sous forme de wrappers fins vers `@kotbo/ui`, reliés à Paraglide via `kotboUiBridge.ts`.
* **AegisAI** consomme directement `@kotbo/ui` et `@kotbo/ui/analytics` (`DashboardShell`, `AnalyticsChartCard`) tout en conservant sa petite touche visuelle plus moderne (rayon `1.25rem`, espacement `1.25rem`, palette bleu/slate) via de simples variables CSS dans `app.css`.
