<p class="doc-lead">L'<strong>API AegisAI by Kotbo</strong> (<code>https://aegisai.kotbo.fr</code>) analyse le texte d'un message et renvoie son score de toxicité et son émotion dominante. Vous pouvez l'utiliser dans n'importe quel bot Discord ou application HTTP, indépendamment de Kotbo.</p>

:::note[Module Kotbo ou API autonome]
Si vous utilisez déjà le bot Kotbo sur votre serveur, aucune clé n'est nécessaire : activez simplement **Protection → AegisAI** dans le dashboard (voir [AegisAI sur Kotbo](/dashboard/moderation/aegis/)). Cette page concerne l'API développeur autonome sur `aegisai.kotbo.fr`.
:::

:::note[Bêta gratuite]
L'API AegisAI est actuellement en phase **Bêta gratuite** : aucune carte bancaire n'est demandée et un plafond par défaut de **60 requêtes par minute** s'applique par clé. L'onglet **Facturation** du tableau de bord prépare les futures offres.
:::

## Obtenir une clé API

La connexion se fait uniquement via **Discord** (il n'est plus possible de se connecter avec une clé API).

1. Ouvrez l'[Espace membre AegisAI ↗](https://aegisai.kotbo.fr/portal) et cliquez sur **Connexion avec Discord**.
2. Cochez **M'avertir par message privé Discord quand ma clé est prête** si vous souhaitez recevoir une notification directe (cela ajoute l'autorisation de vous joindre au serveur Discord commun pour ouvrir vos MP).
3. Dans votre espace membre, ouvrez l'onglet **Clés API** puis remplissez le formulaire **Demander une clé** :
   * **Nom du bot ou projet** : pour identifier votre clé dans les statistiques ;
   * **Description** : l'usage prévu pour votre bot ou service ;
   * **Organisation** (facultatif) : pour rattacher directement la clé à une organisation existante.
4. Une fois la demande validée par l'équipe, vous recevez un **MP Discord** (et une alerte dans votre espace membre) avec un lien direct vers la clé (`?key=...`).

:::caution[Révélation unique du token]
Pour votre sécurité, le token n'est **jamais envoyé en clair par message privé** sur Discord. Cliquez sur le lien reçu pour ouvrir votre tableau de bord et révéler la clé une seule fois. En cas de perte, utilisez **Régénérer la clé** pour obtenir un nouveau token et invalider l'ancien.
:::

## Gérer ses clés, statistiques et organisations

Votre espace membre AegisAI regroupe quatre onglets :

* **Statistiques** : suivez le volume d'appels, la répartition sain/toxique et les courbes d'activité. Vous pouvez filtrer la vue pour toutes vos clés, une organisation précise ou une clé individuelle.
* **Clés API** : révélez un nouveau token, lancez une rotation de clé, révoquez une clé, changez son organisation ou gérez ses accès. Chaque clé peut être déléguée à un autre compte Discord avec le rôle **manager** (lecture et rotation/révocation) ou **viewer** (lecture seule des statistiques).
* **Organisations** : créez une organisation pour regrouper les clés d'une équipe ou d'un projet, et ajoutez des membres par identifiant Discord avec le rôle **owner**, **admin** ou **member**.
* **Facturation** : affiche l'offre en cours (**Bêta gratuite**) ainsi que l'aperçu de la structure tarifaire prévue après la bêta.

Vous pouvez activer ou désactiver les notifications par MP Discord à tout moment depuis les préférences affichées en haut de votre espace membre.

## Utiliser l'API

### Authentification

Toutes les routes d'analyse attendent votre token dans l'en-tête HTTP `Authorization` :

```http
Authorization: Aegis VOTRE_TOKEN
Content-Type: application/json
```

Stockez ce token dans une variable d'environnement côté serveur (par exemple `AEGIS_API_TOKEN`) et ne l'exposez jamais côté client ou dans un dépôt public.

### Endpoints disponibles

Les trois routes d'analyse acceptent une requête `POST` avec un corps JSON :

* `text` *(obligatoire, chaîne)* : le texte à analyser (entre 1 et 4 000 caractères).
* `save` *(facultatif, booléen, défaut `false`)* : disponible sur `/analyze` et `/scan`. Si `true`, le message rejoint la file de triage humain pendant 30 jours maximum pour améliorer le modèle.

| Méthode | Route | Auth | Réponse |
| --- | --- | --- | --- |
| `POST` | `/analyze` | Clé API | `{"toxicity": 0.9231, "is_toxic": true}` |
| `POST` | `/emotion` | Clé API | `{"label": "joie", "score": 0.8123}` |
| `POST` | `/scan` | Clé API | `{"toxic": {"toxicity": 0.9231, "is_toxic": true}, "emotion": {"label": "colère", "score": 0.8123}}` |
| `GET` | `/health` | Public | `{"status": "ok", "engine": "Aegis API Rust", "version": "0.1.0", "uptime_secs": 3600}` |

Le booléen `is_toxic` passe à `true` lorsque `toxicity` dépasse `0.85`. Si votre bot a besoin d'un seuil plus strict ou plus souple, comparez directement le champ `toxicity` à votre propre valeur.

### Limites de débit et codes HTTP

Chaque clé dispose d'une limite par minute calculée sur une **fenêtre glissante de 60 secondes** (`60` requêtes par minute par défaut, ajustable côté administration de `1` à `10 000`).

| Code | Signification |
| --- | --- |
| `200` | Réponse JSON du modèle. |
| `400` | Champ `text` vide ou manquant (`No text provided`). |
| `401` | En-tête `Authorization` manquant ou ne commençant pas par `Aegis `. |
| `403` | Token invalide ou révoqué. |
| `413` | Texte supérieur à 4 000 caractères. |
| `429` | Limite de requêtes par minute dépassée sur la fenêtre de 60 secondes. |
| `500` / `503` | Erreur interne ou modèle ONNX momentanément indisponible. |

## Exemples d'intégration

<Tabs>
  <TabItem label="cURL">
    ```bash
    curl -X POST "https://aegisai.kotbo.fr/scan" \
      -H "Authorization: Aegis $AEGIS_API_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{"text":"Message à analyser","save":false}'
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const response = await fetch('https://aegisai.kotbo.fr/scan', {
      method: 'POST',
      headers: {
        Authorization: `Aegis ${process.env.AEGIS_API_TOKEN}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        text: 'Message à analyser',
        save: false,
      }),
    });

    if (!response.ok) {
      throw new Error(`Erreur AegisAI (${response.status})`);
    }

    const data = await response.json();
    console.log(data.toxic.is_toxic, data.emotion.label);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os
    import requests

    response = requests.post(
        "https://aegisai.kotbo.fr/scan",
        headers={
            "Authorization": f"Aegis {os.environ['AEGIS_API_TOKEN']}",
            "Content-Type": "application/json",
        },
        json={"text": "Message à analyser", "save": False},
        timeout=5,
    )
    response.raise_for_status()
    data = response.json()
    print(data["toxic"]["is_toxic"], data["emotion"]["label"])
    ```

    ```rust
        .send()
        .await?;

    let data: serde_json::Value = res.error_for_status()?.json().await?;
    ```
