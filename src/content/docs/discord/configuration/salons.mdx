<p class="doc-lead">Sur Discord, le module <strong>Salons</strong> automatise la création d'espaces temporaires, la mise à jour des statistiques dynamiques et assure la sécurité active contre le spam.</p>

:::tip[Configuration du Dashboard]
Pour configurer les compteurs, les générateurs de vocaux et le Honeypot, consultez le [Guide de configuration des salons](/dashboard/configuration/salons).
:::

---

## 1. Fils automatiques

* **Déclenchement** : quand un message arrive dans un salon configuré, Kotbo essaie ses configurations dans l'ordre ; la première qui accepte le message ouvre un fil sous lui, nommé selon ses règles (première ligne, nom de l'auteur, date…).
* **Messages non conformes** : si le salon le prévoit, un message qu'aucune configuration n'accepte est retiré après un délai, avec un court avertissement.
* **Renommer un fil** : c'est le bot qui crée le fil, donc seuls les modérateurs peuvent le renommer depuis Discord. Les autres utilisent `/fil renommer` dans le fil, si la configuration autorise l'auteur ou tout le monde.

---

## 2. Message Sticky (message collé en bas de salon)

* **Ce que voient les membres** : un message du bot qui revient systématiquement en dernière position du salon. Dès que la conversation le fait remonter, Kotbo supprime son ancien envoi et le republie tout en bas.
* **Rythme de renvoi** : le message ne remonte pas à chaque message posté, mais après le nombre de messages défini sur le dashboard, avec un délai minimum entre deux renvois pour ne pas saturer le salon.
* **Aucune notification** : les mentions contenues dans un sticky sont neutralisées à l'envoi. Même un `@everyone` n'y déclenche aucun ping.
* **Rendu** : texte brut par défaut, ou encadré coloré (embed) avec un titre si l'option a été activée.

:::caution[Permissions Discord requises]
Kotbo doit pouvoir **voir le salon** (`VIEW_CHANNEL`) et **y écrire** (`SEND_MESSAGES`). Sans ces deux permissions, le message n'est jamais republié.
:::

---

## 3. Salons Stats (Compteurs dynamiques)

* **Rendu visuel** : Les statistiques du serveur sont affichées directement dans le nom de salons vocaux dédiés (ex: `Membres : 1 254` ou `En Ligne : 452`).
* **Fréquence de rafraîchissement** : En raison des limitations imposées par l'API Discord (Rate Limits), Kotbo met à jour les noms de ces salons **toutes les 10 minutes**. Les changements de statistiques ne sont donc pas immédiats mais lissés dans le temps.

## 4. Créer son salon (Salons vocaux temporaires)

Ce système permet à vos membres de créer et de gérer de manière autonome leur salon vocal.

### Étape 1 : Création du salon vocal
1. Le membre rejoint le salon vocal générateur configuré (ex: `Créer un salon`).
2. Kotbo le déplace instantanément dans un nouveau salon vocal temporaire qu'il vient de créer (ex: `Salon de Jean`).

### Étape 2 : L'embed de contrôle interactif
En parallèle, Kotbo envoie un message d'administration interactif (Embed) dans le chat textuel associé à ce salon vocal temporaire. Le créateur du salon (propriétaire) peut piloter les accès à l'aide des boutons :

* **Verrouiller / déverrouiller** : Rend le salon privé. Si verrouillé, les autres membres ne peuvent plus s'y connecter de force.
* **Limite** : Ouvre un formulaire Discord pour définir la limite d'utilisateurs autorisés.
* **Renommer** : Ouvre un formulaire pour modifier le nom du salon.
* **Chat** : Ouvre ou ferme le chat textuel du salon. Fermé, seuls le propriétaire et les membres autorisés y écrivent ; rouvert, le chat retrouve l'accès prévu par la catégorie du salon.
* **Expulser** : Éjecte un utilisateur indésirable connecté dans le vocal.
* **Bannir** : Expulse et interdit définitivement à un membre de rejoindre ce salon.
* **Ajouter** : Donne l'accès explicite à un membre précis, même si le salon est verrouillé.
* **Transférer** : Donne la propriété du salon à un autre membre présent dans le vocal. Le nouveau propriétaire reçoit les pouvoirs accordés par la configuration du serveur.
* **Récupérer** : Permet de revendiquer la propriété du salon si le créateur d'origine est parti et que le salon est devenu orphelin.
* **Réserver** : Limite l'accès à un rôle Discord spécifique sélectionné depuis un menu déroulant.

### Étape 3 : Nettoyage automatique
Dès que le dernier membre connecté quitte le salon vocal temporaire, Kotbo **supprime automatiquement et définitivement** le salon et le chat associé.

## 5. Salon Honeypot (Piège Anti-Spam)

* **Le piège** : Le bot crée ou surveille un salon textuel attractif (ex: `#do-not-type-here` ou `#anti-spam-verification`) visible par tout le monde, en particulier les nouveaux membres.
* **Le déclencheur** : Tout message envoyé dans ce salon par un membre normal ou un bot de spam déclenche le Honeypot.
* **La sanction automatique** : Le bot supprime instantanément le message et applique la sanction sélectionnée (bannissement, timeout de 28 jours, kick ou avertissement) sans avertissement préalable.
* **L'immunité du staff** : Les administrateurs et modérateurs du serveur sont immunisés et peuvent écrire dans le salon Honeypot par erreur sans déclencher de sanction.
