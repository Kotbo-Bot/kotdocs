<p class="doc-lead">Le module <strong>Réputation</strong> permet à vos membres de se remercier entre eux. Contrairement à l'XP, qui récompense la quantité d'activité, la réputation récompense l'utilité perçue par les autres.</p>

:::note[Où la trouver]
Section **Niveaux → Réputation** : [Ouvrir la réputation ↗](https://dash.kotbo.fr/reputation).
Les votes se donnent depuis Discord ; le dashboard sert à les consulter. Les commandes `/rep` sont détaillées dans [Niveaux, classements et réputation](/discord/xp/progression/).
:::

:::note[Ce que le bot refuse]
Un membre dispose de **trois votes par jour**, comptés dans le fuseau du serveur. Au-delà, le vote est refusé - et un vote qui passerait malgré tout en cas de double envoi est annulé après coup. On ne peut ni se voter soi-même, ni voter pour un bot.
:::

---

## Les indicateurs

Trois chiffres résument l'activité du module :

* **Total de votes** : le nombre de votes donnés depuis la mise en service.
* **Votants uniques** : combien de membres différents ont voté.
* **Total rep donné** : le cumul des points distribués.

:::tip[Lire l'écart]
Un grand nombre de votes pour peu de votants uniques signale souvent quelques membres très actifs plutôt qu'une pratique répandue. C'est le signal à surveiller pour éviter les échanges de complaisance.
:::

---

## Classement Réputation

La liste classe les membres par réputation reçue. Tant que personne n'a voté, Kotbo affiche *Aucun vote pour le moment* et précise que les votes entre membres apparaîtront ici.

---

## Votes récents

Le bloc **Votes récents** montre les derniers échanges au fil de l'eau : qui a remercié qui, et quand. C'est la vue à consulter pour repérer rapidement un comportement anormal.

Quand rien n'a été donné récemment, la section affiche *Aucun vote récent*.

---

## Lien avec les autres modules

Les [Quêtes](/dashboard/economie/quetes/) peuvent inclure un objectif **Donner des +rep**, ce qui encourage la pratique auprès des membres qui n'y pensent pas d'eux-mêmes.
