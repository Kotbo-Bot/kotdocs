<p class="doc-lead">Le <strong>Journal d'activité</strong> conserve l'historique des actions de configuration effectuées sur votre serveur. Il répond à la question « qui a changé ce réglage ? ».</p>

:::note[Où la trouver]
Section **Modération → Actions du staff** : [Ouvrir le journal ↗](https://dash.kotbo.fr/activity).
C'est un module **cœur** : il ne peut pas être désactivé depuis la page Modules, précisément pour qu'aucune manœuvre ne puisse effacer sa propre trace.
:::

---

## Les indicateurs

Trois cartes résument la période affichée :

* **Actions (Total)**, sous-titre *Configuration* : le nombre d'actions enregistrées.
* **Modules**, sous-titre *Sources* : le nombre de modules distincts concernés.
* **Utilisateurs**, sous-titre *Unique* : le nombre de personnes différentes ayant agi.

---

## Parcourir le journal

Le tableau affiche les colonnes **Horodatage**, **Utilisateur**, **Module / Source**, **Action**, **Détails** et **Type**.

* Le champ **Recherche** accepte une action, des détails, un module ou un utilisateur.
* Les en-têtes de colonnes sont triables.
* Le bouton **Réinitialiser filtres et tri** remet le tableau à son état initial.
* Un compteur indique le nombre d'événements affichés sur le total.

Une action déclenchée par le bot lui-même porte le type **Automatique** ; les autres portent le nom de la source qui les a produites.

Si aucune ligne ne correspond, Kotbo affiche *Aucun événement ne correspond à votre recherche*.

---

## À quoi cela sert concrètement

* Retrouver **quand** un salon de logs a été changé, et par qui.
* Vérifier qu'une modification annoncée par un membre du staff a bien été appliquée.
* Reconstituer la chronologie après un incident de configuration.

:::tip[Complémentaire aux logs Discord]
Le journal d'activité couvre les actions **sur le dashboard et le bot**. Pour les événements survenus **sur Discord** (messages, sanctions, mouvements vocaux), consultez la page [Logs & activités Discord](/dashboard/moderation/logs/).
:::
