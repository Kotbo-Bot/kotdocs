<p class="doc-lead">Le <strong>Planning</strong> réunit sur un même agenda les réunions, les appels Discord, les absences et les tâches de votre équipe.</p>

:::note[Où la trouver]
Section **Équipe → Planning** : [Ouvrir le planning ↗](https://dash.kotbo.fr/planning).
Il faut être enregistré comme membre du staff pour y créer quoi que ce soit.
:::

:::note[Les heures suivent le fuseau du serveur]
Toutes les dates saisies sur cette page - absences, appels, tâches - sont interprétées dans le **fuseau du serveur**, rappelé sous les champs par *Heure interprétée dans …* et réglé depuis l'[accueil du dashboard](/dashboard/general/accueil/).
:::

## Lire l'agenda

Quatre calendriers se superposent, activables séparément dans **Mes calendriers** :

| Calendrier | Contenu |
| --- | --- |
| **Réunions** | Les points d'équipe, détaillés [plus bas](#les-réunions). |
| **Appels Discord** | Les appels vocaux planifiés. |
| **Absences** | Les indisponibilités déclarées. |
| **Tâches** | Les tâches assignées. |

Le panneau **Personnes** filtre l'agenda sur un ou plusieurs membres, avec les raccourcis **Aucun** et **Tous**.

La vue **Ma journée** affiche vos échéances du jour et, quand il n'y a rien, la mention *Ta journée est libre !*.

## Les réunions

Les réunions ont quitté leur page à part : elles se créent et se suivent ici. L'ancienne adresse `/meetings` ouvre le Planning.

### Planifier une réunion

<div class="step-list">
  <div class="step-item"><div><h3>Ouvrez Nouvel événement</h3><p>Choisissez le type <strong>Réunion</strong> en haut de la fenêtre.</p></div></div>
  <div class="step-item"><div><h3>Renseignez le titre et le créneau</h3><p>Le titre est obligatoire, la fin doit suivre le début, et une réunion déjà passée est refusée.</p></div></div>
  <div class="step-item"><div><h3>Rédigez l'ordre du jour</h3><p>La description est publiée avec l'annonce.</p></div></div>
  <div class="step-item"><div><h3>Enregistrez</h3><p>Kotbo annonce l'événement sur Discord et active les boutons de réponse.</p></div></div>
</div>

Sous les dates, Kotbo rappelle dans quel fuseau l'heure est interprétée. Pour une réunion, le bouton **Changer** permet de la saisir dans un autre fuseau, pour cette réunion seulement.

Le salon d'annonce et le salon vocal des réunions se règlent dans [Réglages du serveur](/dashboard/configuration/centre-gestion/), onglet **Salons et rôles** : champs **Annonces réunions** et **Vocal réunions**.

### Suivre une réunion

Cliquez sur une réunion de l'agenda pour ouvrir sa fiche. Elle passe par les statuts **Planifiée**, **En cours**, **Terminée** et **Annulée** :

* **Démarrer** la bascule en cours, **Terminer** la clôt ;
* la **Liste des présences** compte les **Présents**, **Excusés** et **Absents**. La présence est relevée dans le salon vocal, et une absence déclarée sur le créneau excuse le membre automatiquement.

### Supprimer une réunion

La suppression est définitive. Kotbo demande ensuite s'il faut aussi nettoyer Discord : **Supprimer l'événement Discord**, **Supprimer le message d'annonce** et **Supprimer les notifications internes**.

## Déclarer une absence

<div class="step-list">
  <div class="step-item"><div><h3>Créez un élément de type Absence</h3><p>Depuis <strong>Nouvel événement</strong>.</p></div></div>
  <div class="step-item"><div><h3>Renseignez le motif</h3><p>Le <strong>motif de l'absence</strong> est obligatoire. Le type se choisit parmi <em>Vacances / Congés</em>, <em>Maladie / Médical</em>, <em>Examens / Études</em> ou <em>Autre motif</em>.</p></div></div>
  <div class="step-item"><div><h3>Choisissez le supérieur à notifier</h3><p>Ce champ est obligatoire : c'est lui qui recevra la demande.</p></div></div>
</div>

Une absence est <span class="dash-badge warn">En attente</span> jusqu'à sa validation, puis <span class="dash-badge active">Approuvé</span>.

### Notifications d'absence

La configuration des alertes permet d'activer un **relai Discord** : un message est envoyé dans un **salon des alertes** choisi, avec un **rôle à mentionner**, et éventuellement via une **URL de webhook Discord**.

## Planifier un appel

Un appel crée un salon vocal ou une conférence à une date donnée.

* **Salon temporaire** ou **Salon existant**.
* Type **Vocal** ou **Conférence**.
* **Supprimer quand il est vide** : nettoie le salon temporaire après l'appel.
* **Invités - staff** et **Invités - membres du serveur** : la recherche porte sur les membres du serveur.

### Qui peut créer des appels

Le bouton **Permissions appels** ouvre le réglage :

* **Tout le monde** : tous les membres ayant accès au dashboard staff.
* **Rôles / membres précis** : une liste de **rôles autorisés** et de **membres autorisés**.

## Tâches et rappels

Une **tâche** porte un titre, une description, une **priorité** (*basse*, *moyenne*, *haute*) et un assignataire. Les tâches marquées **Important** remontent en tête.

Sur n'importe quel élément de l'agenda, le bloc **Rappels** programme une notification :

* une **date et heure** ;
* un **canal de réception** : *Message Privé* ou *Ce salon Discord* ;
* une **note** libre, par exemple *Réunion dans 5 min*.

Chaque rappel affiche ensuite s'il est *(Planifié)* ou *(Envoyé)*, et peut être supprimé.
