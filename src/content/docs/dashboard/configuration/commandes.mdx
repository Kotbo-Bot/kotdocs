<p class="doc-lead">Le module <strong>Commandes</strong> permet de restreindre l'utilisation des commandes slash de Kotbo sur votre serveur. C'est l'outil indispensable pour s'assurer que vos commandes sensibles ne sont pas utilisées par n'importe qui, n'importe où.</p>

:::tip[Côté Discord]
Pour savoir comment les commandes slash se comportent sur Discord et comment les restrictions s'appliquent en direct, consultez le [Guide d'utilisation des commandes Discord](/discord/configuration/commandes).
:::

:::note[Disponibilité]
La gestion des droits d'exécution est disponible sous **Réglages → Commandes** dans le dashboard : [Accéder au module Commandes ↗](https://dash.kotbo.fr/command-access).
Seuls les membres possédant les droits d'administration ou les rôles autorisés à configurer le bot peuvent modifier ces paramètres.
:::

---

## Structure de la page

La page est divisée en deux onglets principaux, situés sous le titre :
* **Permissions** : l'interface de configuration permettant de définir les règles d'accès.
* **Structure** : liste complète des commandes de Kotbo disponibles sur votre serveur, avec leur description, leurs **paramètres** et leurs **sous-commandes**. Chaque paramètre y est décrit par son type (*Texte*, *Nombre*, *Membre*, *Salon*, *Rôle*, *Fichier*…) et son statut, **Requis** ou **Optionnel**.

Trois indicateurs résument l'état du serveur en haut de page : **Commandes**, **Restrictions** et **Désactivées**.

Une **barre de recherche**, des **catégories** (*Toutes*, *Modération*, *Administration*, *Communauté*, *Économie*, *Fun*, *Utilitaire*) et des filtres d'état (*Avec restrictions*, *Sans restriction*, *Désactivées*) permettent de retrouver rapidement une commande.

## Couper une commande

Chaque carte de commande porte un interrupteur. Coupé, il désactive la commande pour tout le serveur.

:::caution[Y compris pour les administrateurs]
*Commande coupée pour tout le serveur, administrateurs compris. Réactivez-la pour configurer ses accès.* Une commande désactivée porte le badge **Désactivée** et ses réglages d'accès sont masqués.
:::

## Configurer les restrictions d'une commande

Sur la carte d'une commande active, les **Rôles autorisés** se règlent directement. Le bloc **Restrictions avancées** se déplie pour les salons, les rôles bloqués et les membres.

Vous pouvez restreindre une commande selon trois critères cumulatifs :

### 1. Rôles
Détermine quels groupes d'utilisateurs peuvent exécuter la commande :
* **Rôles autorisés** : seuls les membres possédant l'un de ces rôles pourront utiliser la commande.
* **Rôles bloqués** : les membres possédant l'un de ces rôles seront bloqués, même s'ils ont les droits Discord par défaut.

*Aucun rôle sélectionné* signifie **comportement Discord par défaut**, selon les permissions de la commande. Les administrateurs gardent toujours accès aux commandes activées.

### 2. Salons
Détermine dans quels salons la commande est active :
* Aucun salon : *Exécutable partout*.
* **Salons autorisés** : *Limitée aux salons configurés*.
* **Salons bloqués** : *Interdite dans les salons configurés*.

### 3. Membres
Permet de cibler précisément des membres par leur identifiant Discord. Saisissez l'**ID Discord**, puis **Autoriser** ou **Bloquer**.

Un **Résumé de la règle** rappelle en une ligne ce que la configuration produit : rôles, salons et membres autorisés ou bloqués.

Les **Actions rapides** remettent tout à zéro : **Vider salons**, **Vider rôles**, **Vider membres** ou **Tout supprimer**.

:::tip[Discord sait aussi le faire]
Ces permissions peuvent également se gérer directement dans Discord, via **Paramètres du serveur → Intégrations**.
:::

## Détection et résolution des conflits

Il arrive parfois qu'une configuration comporte des règles contradictoires (par exemple, si vous ajoutez le rôle `@Moderator` à la fois dans les rôles autorisés et dans les rôles bloqués).

* **Alerte de conflit** : Le dashboard détecte automatiquement ces anomalies et affiche une alerte d'avertissement rouge.
* **Résoudre les conflits** : Un bouton apparaît dans l'alerte pour nettoyer automatiquement la configuration en supprimant les doublons conflictuels en un clic.

## Sauvegarde

:::caution[Barre de sauvegarde]
Comme pour toutes les pages de configuration, les restrictions ne sont pas appliquées tant que vous n'avez pas cliqué sur **Enregistrer** dans la barre verte en bas de votre écran.
:::
