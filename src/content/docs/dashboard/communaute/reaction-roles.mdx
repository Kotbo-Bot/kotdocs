title: Rôles par réaction
description: Publiez des messages à boutons pour que vos membres s'attribuent eux-mêmes leurs rôles.
---

<p class="doc-lead">Le module <strong>Rôles par réaction</strong> publie sur Discord un message à boutons. Un clic attribue le rôle associé ; selon le mode choisi, un second clic le retire, ou en prendre un autre retire le précédent.</p>

:::note[Où la trouver]
Section **Communauté → Rôles par réaction** : [Ouvrir les rôles par réaction ↗](https://dash.kotbo.fr/reaction-roles).
Kotbo doit disposer de la permission **Gérer les rôles**, et son rôle doit être **au-dessus** des rôles qu'il attribue dans la hiérarchie du serveur.
:::

---

## Publier un message de rôles

**Publier un message de rôles** ouvre une fenêtre en quatre étapes, avec l'**Aperçu sur Discord** dans un volet dépliant. Sur un serveur sans menu, la page propose directement les modèles.

<div class="step-list">
  <div class="step-item"><div><h3>Partir d'un modèle (facultatif)</h3><p><strong>Couleurs</strong> (une couleur de pseudo à la fois), <strong>Pronoms</strong>, <strong>Notifications</strong>, ou <strong>Vide</strong>. Le modèle remplit le menu avec des rôles proposés ; rien n'est créé tant que vous ne publiez pas.</p></div></div>
  <div class="step-item"><div><h3>Combien de rôles un membre peut prendre ?</h3><p>Voir <a href="#les-trois-modes">les trois modes</a>.</p></div></div>
  <div class="step-item"><div><h3>Les boutons</h3><p>Pour chacun : un <strong>Émoji</strong> (facultatif), le <strong>Texte du bouton</strong> et le <strong>Rôle donné</strong>. <strong>Ajouter un bouton</strong> en crée d'autres ; la poignée les réordonne par glisser-déposer, ou avec les flèches haut et bas.</p></div></div>
  <div class="step-item"><div><h3>Où le publier</h3><p><strong>Titre du message</strong>, <strong>Salon de destination</strong> et <strong>Texte du message</strong> (vide : Kotbo garde le texte qui explique comment prendre les rôles). Puis <strong>Publier le message</strong>.</p></div></div>
</div>

Un rôle proposé par un modèle qui n'existe pas encore est créé à la publication, sans aucune permission ; Kotbo dit combien de rôles il va créer. **Choisir un rôle existant à la place** le remplace par un rôle du serveur.

Fermer la fenêtre (ou **Échap**) avant de publier demande une confirmation : *Fermer sans publier* efface ce que vous aviez préparé.

:::caution[Texte et rôle obligatoires]
Tous les boutons doivent avoir un texte **et** un rôle, sinon Kotbo refuse la publication.
:::

---

## Les trois modes

| Mode | Ce que fait un clic |
| --- | --- |
| **Plusieurs** | Le membre prend et retire les rôles qu'il veut. |
| **Plusieurs, pour de bon** | Une fois pris, un rôle ne se retire plus d'ici. |
| **Un seul** | En prendre un retire l'autre, recliquer le retire. Pour les couleurs ou la région. |

Dans les modes à plusieurs rôles, chaque bouton peut s'écarter du menu dans ses options : **Second clic sur ce bouton** → **Comme le menu**, **Garde le rôle** ou **Retire le rôle**. On mélange ainsi un rôle de notification qu'on peut couper et un rôle d'accès qu'on ne rend pas.

Le texte sous le titre suit le mode retenu : Kotbo annonce que les rôles ne se retirent pas d'ici, qu'il n'en faut prendre qu'un, ou que certains ne se retirent plus une fois obtenus.

---

## Options secondaires

Le volet **Options secondaires** d'un bouton ou du menu règle le reste :

* la couleur Discord du bouton (**Gris**, **Bleu**, **Vert** ou **Rouge**), sans effet sur l'attribution ;
* **Nombre de membres sur les boutons** : affiche « Rouge · 12 », le nombre de membres qui ont le rôle (pas de clics : basculer plusieurs fois ne le gonfle pas), mis à jour quelques secondes après un clic ;
* **Couleur de la barre** du message, ou **Par défaut**.

---

## Gérer les menus publiés

Chaque menu publié s'affiche en carte, comme un mini-aperçu Discord, avec son salon, ses rôles et le nombre de membres par rôle.

* **Modifier** : rouvre la fenêtre. Le message Discord est mis à jour dès l'enregistrement, rien à republier.
* **Dupliquer** : crée une copie du menu, à publier ailleurs.
* **Supprimer du tableau de bord** : supprime aussi le message Discord.

:::caution[Changer de salon republie le panneau]
Si vous choisissez un autre salon en modifiant un menu, Kotbo publie un nouveau message dans le salon choisi et **supprime l'ancien**. Les membres perdent le message d'origine, ses épingles et les liens qui pointaient dessus.
:::

Kotbo signale sur chaque carte ce qui empêche le menu de fonctionner : le message n'est plus sur Discord, ou des rôles qu'il ne peut pas donner (rôle introuvable, géré par une intégration, placé au-dessus du bot, ou permission **Gérer les rôles** manquante). Le membre qui clique sur un rôle bloqué reçoit lui aussi une explication.

Les rôles pris et retirés sont suivis dans les [Journaux](/dashboard/moderation/logs/), l'onglet **Rôles par réaction** des [Statistiques](/dashboard/general/analytics/) et les [Déclencheurs](/dashboard/communaute/declencheurs/).
