<p class="doc-lead">Le module <strong>Salons Fun</strong> permet de créer des espaces ludiques et automatisés sur votre serveur Discord. Kotbo s'occupe de gérer les règles et de maintenir le score en temps réel pour plusieurs jeux classiques.</p>

:::tip[Côté Discord]
Pour comprendre les règles de jeu et l'expérience utilisateur sur Discord, consultez le [Guide de jeu des Salons Fun](/discord/communaute/salons-fun).
:::

:::note[Disponibilité]
Ces salons de jeux sont configurables depuis la section **Communauté → Salons fun** de votre dashboard : [Accéder au module Salons Fun ↗](https://dash.kotbo.fr/fun).
Les modifications nécessitent les permissions d'administration de Kotbo sur le serveur.
:::

## Salon de comptage

Le jeu de comptage invite vos membres à compter le plus loin possible, dans l'ordre croissant (1, 2, 3, 4, etc.). 

### Configuration du salon
1. Accédez à **Communauté → Salons fun**.
2. Dans le premier bloc **Salon de comptage**, ouvrez le menu déroulant **Salon Discord** et sélectionnez le salon dédié au jeu.
3. Le bloc affiche en temps réel :
   * **Nombre** : Le score actuel de la chaîne de comptage.
   * **Dernier joueur** : L'identifiant (ID) du dernier utilisateur ayant validé un nombre.
4. Si un membre fait une erreur ou que vous souhaitez remettre la partie à zéro, cliquez sur **Réinitialiser le comptage** (un message de confirmation s'affiche).

:::note[Deux nombres envoyés en même temps]
Un seul des deux compte : le message perdant est supprimé avec un avertissement, **sans casser la chaîne**. La même règle protège tous les salons de jeu, dont les messages sont traités dans l'ordre, salon par salon.
:::

## One Word Story

Ce jeu collaboratif invite la communauté à écrire une histoire collective, un seul mot à la fois.

### Configuration du salon
1. Dans le bloc central **One Word Story**, sélectionnez le salon textuel dédié à l'histoire dans le menu déroulant **Salon Discord**.
2. La zone de statut affiche l'identifiant (ID) du **Dernier auteur** ayant écrit un mot.
3. Ce salon est entièrement régulé par le bot : les mauvais messages sont supprimés et les doubles envois bloqués sans intervention des modérateurs.

## Nombre Mystère

Proposez à vos membres de deviner un nombre secret généré aléatoirement par le bot.

### Configuration du salon
1. Dans le troisième bloc **Nombre Mystère**, sélectionnez le salon textuel de jeu dans le menu déroulant **Salon Discord**.
2. Le bloc affiche la **Cible mystère** (visible uniquement par le staff sur le dashboard).
3. Pour changer la valeur cible ou lancer une nouvelle partie manuellement, cliquez sur **Générer une nouvelle cible**. Une confirmation *Générer un nouveau nombre mystère ?* s'affiche avant validation.

---

## Chaîne de mots

Chaque mot doit commencer par la dernière lettre du précédent.

### Configuration du salon
1. Dans le bloc **Chaîne de mots**, sélectionnez le salon dédié dans le menu déroulant **Salon Discord**.
2. Le bloc affiche le **Dernier mot** joué et le **Dernier joueur**.
3. Le bouton **Réinitialiser la chaîne** repart de zéro, après confirmation.
4. Les mots à ligature (`cœur`, `œuvre`) sont acceptés, et un mot ne peut pas se terminer par un tiret.

## Rébus Emoji

Les membres devinent l'expression cachée derrière une suite d'emojis.

### Configuration du salon
1. Dans le bloc **Rébus Emoji**, sélectionnez le salon dédié.
2. Le bloc affiche l'**Indice actuel** : c'est la même suite d'emojis que le bot publie dans le salon, pas un secret.
3. Le bouton **Nouveau rébus** en génère un autre, après confirmation. Kotbo l'annonce aussitôt dans le salon, comme après chaque bonne réponse.

### Écrire ses propres rébus

Sous le salon, la section **Rébus du serveur** tient votre propre liste : ils sont tirés au hasard dans le salon, au même titre que ceux fournis par Kotbo. Le compteur affiche votre total sur un maximum de **200**.

<div class="step-list">
  <div class="step-item"><div><h3>Composez les emojis</h3><p>Tapez-les ou choisissez-les dans le sélecteur d'emojis.</p></div></div>
  <div class="step-item"><div><h3>Listez les réponses acceptées</h3><p>Une réponse par ligne, par exemple <em>le roi lion</em> puis <em>roi lion</em>. Les accents, les majuscules et la ponctuation sont ignorés à la comparaison.</p></div></div>
  <div class="step-item"><div><h3>Ajoutez le rébus</h3><p>Il pourra sortir dès le prochain tirage. Chaque rébus se modifie et se supprime ensuite depuis sa carte.</p></div></div>
</div>

L'interrupteur **Inclure les rébus fournis** mélange vos rébus avec ceux de Kotbo. Désactivé, seuls les vôtres sortent - sauf si vous n'en avez aucun. Le lien **Voir les rébus fournis** déplie la liste livrée par défaut.

:::tip[Plusieurs formulations valent mieux qu'une]
Un rébus n'est validé que si la réponse tapée figure dans la liste. Prévoyez les variantes courantes (avec et sans article, singulier et pluriel) plutôt que de compter sur une seule tournure.
:::

## Ni Oui Ni Non

Interdit de répondre par oui ou par non.

### Configuration du salon
1. Dans le bloc **Ni Oui Ni Non**, sélectionnez le salon dédié.
2. Ce salon est régulé automatiquement : tout message contenant « oui » ou « non » est supprimé.

---

## Emoji Uniquement

Seuls les emojis sont autorisés dans le salon.

### Configuration du salon
1. Dans le bloc **Emoji Uniquement**, sélectionnez le salon dédié.
2. Ce salon est régulé automatiquement : tout message contenant autre chose que des emojis est supprimé. Les emojis du serveur, les teintes de peau, les drapeaux et les touches numérotées passent sans encombre.

---

## Mode punitif

Un interrupteur commun à tous les jeux décide de ce qui se passe en cas d'erreur.

* **Activé** : sur une erreur de comptage ou de chaîne de mots, le jeu **repart de zéro**.
* **Désactivé** : le message fautif est supprimé et son auteur prévenu, **sans casser la progression**.

---

## Sauvegarde des modifications

:::caution[Enregistrement requis]
Dès que vous modifiez l'affectation d'un salon fun, une barre d'action s'affiche en bas de votre écran. Vous devez cliquer sur **Enregistrer** pour que les changements soient appliqués sur votre serveur Discord. Cliquez sur **Réinitialiser** si vous souhaitez annuler vos modifications en cours.
:::
