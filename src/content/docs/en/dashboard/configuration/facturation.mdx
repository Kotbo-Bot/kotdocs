<p class="doc-lead">A server's plan determines which modules are available. The <strong>Billing</strong> page shows the current plan, offers the higher ones, and hands everything payment-related over to Stripe.</p>

:::note[Where to find it]
The **Billing** entry sits at the bottom of the sidebar, above your profile: [Open billing ↗](https://dash.kotbo.fr/billing).
It is not visible to everyone - see *Who can access it* below.
:::

:::note[Plan names]
The page follows your dashboard language, but plan names and descriptions come from the server and stay in French (*Gratuit*, *Sur mesure*…). Prices are shown in euros.
:::

---

## Free, then a single paid plan

The **Gratuit** plan has no time limit: it opens the core modules. The **Plus** plan opens the **whole catalogue**, including modules added later, at the **same price for every server**, whatever its size.

| Plan | Price | What it opens |
| --- | --- | --- |
| **Gratuit** | €0 | The core modules, with no time limit. |
| **Plus** | €5 a month or €30 a year | The whole catalogue, for every server. |

:::note[What the Gratuit plan opens]
Moderation (sanctions, AutoMod, anti-raid, verification, nicknames), logs, welcome and goodbye, rules, reaction roles, embed builder, auto-responses, auto-thread, news and RSS, levels, tickets, giveaways, events and quizzes, suggestions, Starlight, fun channels, analytics, triggers, social networks, YouTube, Twitch, bump reminder and the staff directory.
:::

:::tip[What the full plan adds]
Full staff management (hierarchy, recruitment, mentoring, meetings, time off, tracking lists, polls, discipline, reviews), AegisAI moderation, alt accounts, ban appeals, Code Police, seasons, prestige, clans, drops, economy and RPG, marketplace, quests, reputation, Daily Algo, the community website, campaigns, translation, digest, forms, channel health, the MCP server and cross-server (channel links, partnerships, staff server).
:::

The former **Pro** and **Ultimate** plans are no longer sold. A server subscribed to one keeps it, with the whole catalogue, and its card stays on the page; it can switch to Plus from **Manage my subscription**. A **Sur mesure** agreement (white-label, partnership) is set up with the Kotbo team and reads *Included in your agreement*.

## Referral and free trial

The full plan's trial is only available with a **referral code**. Enter it under **Got a referral code?** before subscribing: the **first 15 days** are free, then your **first invoice gets 10% off**. Without a code, the subscription is paid from day one.

Stripe asks for a card, but only charges it at the end of the trial, and cancelling before then costs nothing. Without a subscription at the end of the trial, the server goes back to **Gratuit**: the core modules keep running, the others pause with their settings kept.

A referral applies once per Discord account and once per server. Your own code does not work for you. When it is no longer possible, the page says why:

* *You already had a trial on a server: referrals apply once per Discord account.*
* *This server already had its trial: referrals no longer apply here.*
* *This server is already subscribed: plan changes are prorated from the Stripe portal.*
* *This plan has no free trial.*

### Your code to share

At the bottom of the **Billing** page, **Your referral code** shows your personal code (`KOTBO-…`) with a **Copy** button, and how many servers have used it. A server that subscribes with this code gets the same benefits: 15 days free, then 10% off its first invoice.

In the setup flow, the code goes into **Tu as un code ? Parrainage, partenaire…**: a `KB-…` code is still an activation code, any other code is taken as a referral code.

## Subscribing and managing

The **Monthly / Yearly** switch changes the prices shown; the yearly option costs half as much (€30 instead of €60). Prices include tax and are **per Discord server**.

The purchase button opens a Stripe-hosted checkout page, then brings you back to billing. While Stripe confirms, the plan may take a few seconds to update on screen.

The checkout page asks you to accept the terms of service: Kotbo opens the modules as soon as the payment is confirmed, which requires your express request for immediate delivery.

Once subscribed, **Manage my subscription** opens the Stripe portal: payment method, invoices, prorated plan changes and cancellation. Access is kept until the end of the period already paid for.

The subscription status is spelled out next to the plan name: *Active*, *Trial period*, *Payment failed*, *Unpaid*, *Cancelled*, *Payment incomplete*, *Payment abandoned* or *Paused*.

After a successful payment, a box confirms the plan chosen, recalls that its modules open within seconds with nothing to reinstall, and offers **See my new modules**.

:::tip[Your server has grown]
Nothing changes: the Plus price does not depend on member count.
:::

### Annual renewal

An **annual** subscription about to renew triggers a prior notice, sent by DM to the payer - or, failing that, posted in a server channel - between two and three months before the due date.

The notice recalls the due date, that renewal is automatic unless cancelled, and that access stays open until that date if you cancel. A subscription already scheduled for cancellation gets none.

:::caution[Payment failed]
When a charge fails, the server keeps its access while Stripe retries. Update your payment method before the cut-off.
:::

## Who can access it

Billing is not open to the whole staff:

* **Server administrators** can reach it and do everything there.
* **The payer** - the account that subscribed - can reach it too, even without being an administrator.
* **Moderators** only reach it if the server opened billing to them, and **read-only**: they see the plan and its status, but cannot pay, change plan or cancel.

---

## Self-hosted instances

On an installation without a Stripe key - self-hosted or white-label - the page shows *Billing is not enabled on this instance*. Every module then follows the server configuration, with no commercial plan. That is normal behaviour, not an error.
