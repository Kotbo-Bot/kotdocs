<p class="doc-lead">The <strong>Inbox</strong> gathers the internal notifications aimed at the staff: moderation alerts, new applications, team summons and system messages.</p>

:::note[Where to find it]
The **General → Notifications** section: [Open the inbox ↗](https://dash.kotbo.fr/notifications).
This is a **core** module, it cannot be disabled.
:::

---

## Filtering by area

Notifications are split into tabs:

| Tab | Content |
| --- | --- |
| **All** | Every notification. |
| **Moderation** | Sanctions, automatic alerts, reports. |
| **Recruitment** | New applications and processing steps. |
| **Staff** | Meetings, absences, team decisions. |
| **System** | Technical messages and instance alerts. |

When a tab is empty, Kotbo says explicitly which one has nothing to show.

---

## Handling a notification

On each entry:

* **View** opens the item concerned: a ticket, an application, a meeting.
* **Mark as read** removes it from the unread counter.

The **Mark all as read** button clears the counter at once, and the refresh button reloads the list.

:::tip[The home widget]
The **Inbox** widget on the [Home](/en/dashboard/general/accueil/) page shows the number of unread notifications. Add it to your layout if you do not visit this page often.
:::
