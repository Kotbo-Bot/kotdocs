<p class="doc-lead">The <strong>Home</strong> page first tells you what is waiting: tickets, approvals, reports, setup steps. Below, a grid of blocks you arrange as you like.</p>

:::note[Where to find it]
It is the dashboard's landing page: [Open home ↗](https://dash.kotbo.fr/).
It is a **core** module: it cannot be disabled.
:::

---

## Needs attention

The **Needs attention** block, at the top of the page, gathers what is waiting for you to act, depending on your permissions: tickets to approve or with nobody assigned, ban appeals, sanction reports to complete, alt accounts to review, absences to approve, your tasks, staff polls you have not voted in, upcoming meetings, applications, pending suggestions, channel health alerts, failed triggers. Each line leads to the page where you act.

You can hide a line that does not concern you; **Show all again** brings it back. When nothing is waiting, the block says so: *No tickets, appeals, reports or approvals waiting.*

### Setup

Under those items, the **Setup** line shows progress (*N of M in place*) and what is missing. **Guide me** opens the page concerned and leads you to the field to fill in; the rest is in [Getting started](/en/dashboard/general/prise-en-main/).

## The blocks

A new server shows five blocks: **Live**, **Activity**, **Moderation**, **Team** and **Recent activity**. Others are added from **Add a block**.

| Block | What it shows |
| --- | --- |
| **Live** | Members, online, in voice and this week's joins. |
| **Activity** | Messages, voice and sanctions over the last 7 days, with the rankings from [Statistics](/en/dashboard/general/analytics/). |
| **Active modules** | How many modules are on, and which ones are failing. |
| **Active channels** | The channels with the most messages. |
| **Moderation** | Sanctions given: warnings, timeouts, bans. |
| **Active members** | The members who post the most. |
| **Notifications** | Your latest [notifications](/en/dashboard/general/notifications/) and alerts. |
| **Team** | Absences to approve and upcoming meetings. |
| **Recent activity** | The latest moderation and settings actions. |
| **Kotbo's language** and **Time zone** | The same settings as in [Server settings](/en/dashboard/configuration/centre-gestion/), close at hand. |
| **Shortcuts** | Links to the planning, modules, statistics and team. |
| **Notes** | A notepad for your reminders, saved on this device. |
| **Your server** | Members, boosts and server owner. |
| **Kotbo resources** | Memory and CPU used by Kotbo, response time and uptime. |
| **What's new** | The latest Kotbo updates. |
| **Getting started** | The first recommended settings. |
| **Clock** | The local date and time. |
| **Economy**, **Levels**, **Tickets**, **Invites**, **Events**, **Polls**, **Staff server** | A preview of the matching module. |

A block whose module is off says so instead of showing empty figures. When a module is failing, a banner says so at the top of the page with **See modules**.

:::note[Language and time zone moved]
**Kotbo's language** and **Time zone** are now set in [Server settings](/en/dashboard/configuration/centre-gestion/), **Overview** tab. The home blocks are still available, but are no longer part of the starting layout.
:::

## Customizing home

The **Customize** button, in the header, switches to edit mode: move, resize or remove blocks, then save.

<div class="step-list">
  <div class="step-item"><div><h3>Add a block</h3><p><strong>Add a block</strong> offers the blocks still hidden.</p></div></div>
  <div class="step-item"><div><h3>Move it</h3><p><strong>Move up</strong> and <strong>Move down</strong> place it in the grid.</p></div></div>
  <div class="step-item"><div><h3>Resize it</h3><p>Drag the block's edge to change its <strong>width</strong> in columns and its <strong>height</strong> in rows.</p></div></div>
  <div class="step-item"><div><h3>Hide what you don't use</h3><p><strong>Hide the block</strong> takes it off the grid.</p></div></div>
  <div class="step-item"><div><h3>Save or cancel</h3><p><strong>Save</strong> keeps the layout; <strong>Cancel</strong> goes back to the previous one.</p></div></div>
</div>

In edit mode, the page menu also offers:

* **Templates**: save the current layout under a name, apply another one, or import a layout from exported text;
* **Export**: download the layout to share it;
* **Reset**: go back to the blocks offered at the start.

---

## In the header

* **Vote** opens Kotbo's page on Top.gg.
* **Refresh** reloads the figures.

If Kotbo restarts, the page shows *Kotbo is restarting, it takes a few seconds*: reconnection is automatic, just wait or click **Retry**.
