<p class="doc-lead">The <strong>Home</strong> page is a fully modular dashboard: you choose which widgets are shown, how big they are and in what order.</p>

:::note[Where to find it]
It is the dashboard's opening page: [Open the home page ↗](https://dash.kotbo.fr/).
This is a **core** module, it cannot be disabled.
:::

## The available widgets

| Widget | What it shows |
| --- | --- |
| **Live stats** | Members, voice, online and growth in real time. |
| **Activity chart** | Messages, voice and sanctions over 7 days. |
| **System status** | Instance health and number of active modules. |
| **Active channels** | Channels ranked by message volume. |
| **Moderation** | Number of sanctions issued. |
| **Active members** | Ranking of the most talkative members. |
| **Inbox** | Internal notifications and system alerts. |
| **Staff management** | Upcoming absences and next meetings. |
| **Recent activity** | Live history of moderation and administration actions. |
| **Action shortcuts** | Quick creation of an absence, a meeting, a staff member and more. |
| **Notes** | A shared notepad, saved locally. |
| **Server info** | Members, boosts, owner. |
| **Bot hosting** | CPU, RAM, API latency and uptime. |
| **Latest news** | The Kotbo changelog. |
| **Quick guide** | Checklist of recommended setup actions. |
| **Clock** | Local date and time. |
| **Bot language** | The language the bot replies in on this server. |
| **Time zone** | The zone used for meetings, calls and reminders. |
| **Economy**, **Levels**, **Tickets**, **Invites**, **Events**, **Polls**, **Staff server** | An overview of the matching module. |

A widget whose module is disabled says so explicitly rather than showing empty figures.

### Bot language

The **Bot language** widget decides what language Kotbo replies in on this server. By default it is on **auto-detection** and follows the Discord server's language; an **explicit choice** - French or English - takes priority, and the **Switch back to automatic** button returns to detection.

Changing the language re-publishes the panels already posted in the new language, and Kotbo reports how many were.

### Time zone

The **Server time zone** widget sets the server's reference time. It is what drives meeting, call and reminder times, as well as scheduled triggers and the opening of the weekly raid.

:::caution[Without a time zone, everything is off]
The bot runs in UTC. While the zone is unset, every date shown or entered is shifted - it is one of the three "Essentials" points on the [Getting set up](/en/dashboard/general/prise-en-main/) page.
:::

## Building your layout

<div class="step-list">
  <div class="step-item"><div><h3>Add a module</h3><p>The <strong>Add a module</strong> button offers the widgets still hidden.</p></div></div>

## Sharing a layout: presets

A layout can be saved as a **preset**, then:

* **applied** in one click on another server;
* **shared** by link, the button copying the address to your clipboard;
* **exported** and **imported** as JSON.

:::tip[One preset per role]
A moderator and an administrator do not need the same things. Prepare a preset per profile and share the link with your team, so everyone gets the view that concerns them.
:::

## The special states

* **Kotbo is restarting, it takes a few seconds**: reconnection is automatic, just wait.
* **A setting is broken**: a **Repair** button is offered to fix the reported configuration.
* System health is summarised as **Optimal**, **Good**, **Degraded** or **Critical**.
