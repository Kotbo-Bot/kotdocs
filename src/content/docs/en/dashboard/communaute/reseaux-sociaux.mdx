<p class="doc-lead">The <strong>Social networks</strong> module watches external accounts and posts an alert in a Discord channel for every new item: YouTube video, Short or live, Twitch stream, GitHub repository activity, Hugging Face release.</p>

:::note[Where to find it]
The **Communication → Social networks** section: [Open social networks ↗](https://dash.kotbo.fr/social-networks). The module is in **beta**.
YouTube and Twitch announcements also depend on the **YouTube** and **Twitch** modules. When one of them is off, the tab says so (*The … module is off*): your follows are kept, but nothing is announced.
:::

The page has four tabs: **YouTube**, **Twitch**, **GitHub** and **Hugging Face**. Each lists its follows; a button opens the add window, and **Edit** reopens the same window on an existing follow.

---

## Shared settings

Each follow has:

* an **Alerts Channel** (by default, the server's public channel);
* an optional **Mention (role to ping)**: a server role, `@everyone` or `@here`. Only the chosen mention can notify: a video or stream title cannot ping the whole server;
* one or more messages. Empty, a message uses Kotbo's default text.

**Stop following** removes a follow without confirmation: an **Undo** button lets you go back for a few seconds.

---

## YouTube

**Follow a YouTube Channel**: the **URL, Handle or Channel Name** field accepts all three forms, for example `https://youtube.com/@cyprien` or just the name. Three messages are set separately under **Messages by alert type**: **Live**, **Video** and **Short**, with the `[title]` and `[channel]` variables.

Click **Add Channel**: it joins the **Followed Channels**.

## Twitch

**Follow a Twitch Streamer**: **Twitch Username or Link** (for example `xqc` or `https://twitch.tv/xqc`) and a **Live Message**. **Follow Streamer** adds them to the **Followed Streamers**, which show **Live** or **Offline** for each.

## GitHub

**Follow a GitHub repository**: the **Repository** (`owner/repo` or its link), the **Commit branch** (empty: the default branch) and the **Alerts to send**: **Commits**, **Releases**, **Pull requests** and **Issues**. The message accepts `[title]`, `[channel]`, `[author]` and `[url]`.

Only what happens after adding is announced, checked every 5 minutes.

## Hugging Face

**Follow on Hugging Face**: pick **What to follow** - a **Model**, a **Dataset**, a **Space** or an **Author** - then the **Repository or author** (`owner/name` or a Hub link). A repository announces its new commits, an author their new models, datasets and spaces.

:::tip[Default message]
The default message is enough in most cases: only customise the alerts you really want to set apart.
:::
