<p class="doc-lead">The <strong>AegisAI by Kotbo API</strong> (<code>https://aegisai.kotbo.fr</code>) scores a message for toxicity and returns its dominant emotion. You can call it from any Discord bot or HTTP application, independently of Kotbo.</p>

:::note[Kotbo module or standalone API]
If you already run Kotbo on your server, you do not need an API key: enable **Protection → AegisAI** directly in the dashboard (see [AegisAI on Kotbo](/en/dashboard/moderation/aegis/)). This page documents the standalone developer API at `aegisai.kotbo.fr`.
:::

:::note[Free Beta]
The AegisAI API is currently in **Free Beta**: no credit card is required, and each key defaults to **60 requests per minute**. The **Billing** tab in the developer dashboard lays the groundwork for future paid tiers.
:::

## Get an API key

All logins now go through **Discord** (logging in directly with an API key is no longer supported).

1. Open the [AegisAI Member Portal ↗](https://aegisai.kotbo.fr/portal) and click **Sign in with Discord**.
2. Tick the Discord DM opt-in option if you want a direct message as soon as your key is approved (this grants permission to add your account to the shared Discord server so DMs can be delivered).
3. In your dashboard, open the **Clés API** (API keys) tab and submit a key request:
   * **Bot or project name**: used to identify the key in your stats;
   * **Description**: what your bot or application does;
   * **Organisation** *(optional)*: attach the new key to an existing team organisation.
4. Once reviewed and approved by the team, you receive a **Discord DM** (plus an in-app notification) containing a direct link to the key (`?key=...`).

:::caution[Single-reveal token]
For security, your raw token is **never sent in plain text over Discord DM**. Follow the link to open your dashboard and reveal the token once. If you lose it, rotate the key from the dashboard to generate a new token and revoke the previous one.
:::

## Manage keys, stats and organisations

Your AegisAI dashboard has four tabs:

* **Statistiques**: track total volume, toxic vs. healthy breakdown and daily charts. Filter metrics across all accessible keys, a single organisation or one specific key.
* **Clés API**: reveal newly approved tokens, rotate or revoke keys, reassign a key to an organisation and manage access. You can assign another Discord user as a **manager** (stats, rotation and revocation) or **viewer** (read-only stats).
* **Organisations**: group keys under a shared team workspace and invite members by Discord ID with the **owner**, **admin** or **member** role.
* **Facturation**: displays your active **Free Beta** plan and the upcoming billing framework.

You can toggle Discord DM notifications on or off at any time from your profile preferences in the header.

## Using the API

### Authentication

Send your API token in the HTTP `Authorization` header on every analysis call:

```http
Authorization: Aegis YOUR_TOKEN
Content-Type: application/json
```

Store the token in a server-side environment variable (such as `AEGIS_API_TOKEN`) and never expose it in public client code.

### Available endpoints

All three analysis endpoints accept a `POST` request with a JSON body:

* `text` *(required, string)*: the text to analyze (1 to 4,000 characters).
* `save` *(optional, boolean, default `false`)*: available on `/analyze` and `/scan`. When `true`, the message enters the human triage queue for up to 30 days to help improve the model.

| Method | Route | Auth | Response |
| --- | --- | --- | --- |
| `POST` | `/analyze` | API key | `{"toxicity": 0.9231, "is_toxic": true}` |
| `POST` | `/emotion` | API key | `{"label": "joie", "score": 0.8123}` |
| `POST` | `/scan` | API key | `{"toxic": {"toxicity": 0.9231, "is_toxic": true}, "emotion": {"label": "colère", "score": 0.8123}}` |
| `GET` | `/health` | Public | `{"status": "ok", "engine": "Aegis API Rust", "version": "0.1.0", "uptime_secs": 3600}` |

`is_toxic` becomes `true` when `toxicity` is above `0.85`. If your bot needs a stricter or more lenient threshold, compare `toxicity` directly against your own value.

### Rate limits and HTTP status codes

Each key has a per-minute quota enforced over a **60-second sliding window** (`60` requests per minute by default, configurable by administrators between `1` and `10,000`).

| Status | Meaning |
| --- | --- |
| `200` | JSON prediction returned by the model. |
| `400` | Empty or missing `text` field (`No text provided`). |
| `401` | Missing `Authorization` header or missing `Aegis ` prefix. |
| `403` | Invalid or revoked API token. |
| `413` | `text` is longer than 4,000 characters. |
| `429` | Per-minute rate limit exceeded inside the 60-second window. |
| `500` / `503` | Internal error or ONNX model temporarily unavailable. |

## Integration examples

<Tabs>
  <TabItem label="cURL">
    ```bash
    curl -X POST "https://aegisai.kotbo.fr/scan" \
      -H "Authorization: Aegis $AEGIS_API_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{"text":"Message to analyze","save":false}'
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const response = await fetch('https://aegisai.kotbo.fr/scan', {
      method: 'POST',
      headers: {
        Authorization: `Aegis ${process.env.AEGIS_API_TOKEN}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        text: 'Message to analyze',
        save: false,
      }),
    });

    if (!response.ok) {
      throw new Error(`AegisAI error (${response.status})`);
    }

    const data = await response.json();
    console.log(data.toxic.is_toxic, data.emotion.label);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os
    import requests

    response = requests.post(
        "https://aegisai.kotbo.fr/scan",
        headers={
            "Authorization": f"Aegis {os.environ['AEGIS_API_TOKEN']}",
            "Content-Type": "application/json",
        },
        json={"text": "Message to analyze", "save": False},
        timeout=5,
    )
    response.raise_for_status()
    data = response.json()
    print(data["toxic"]["is_toxic"], data["emotion"]["label"])
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    use serde_json::json;

    let token = std::env::var("AEGIS_API_TOKEN")?;
    let res = reqwest::Client::new()
        .post("https://aegisai.kotbo.fr/scan")
        .header("Authorization", format!("Aegis {token}"))
        .json(&json!({ "text": "Message to analyze", "save": false }))
        .send()
        .await?;

    let data: serde_json::Value = res.error_for_status()?.json().await?;
    ```
  </TabItem>
